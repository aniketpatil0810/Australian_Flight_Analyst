# ✈️ Flight Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing flight data to extract meaningful insights using **Python, SQL, and Power BI**. The goal is to understand trends in airline operations, passenger capacity, and route performance.

---

## 🛠️ Tech Stack

* **Python** → Data Cleaning & Preprocessing
* **SQL** → Data Analysis & Querying
* **Power BI** → Data Visualization & Dashboard

---

## 📂 Dataset

The dataset contains information about flights, including:

* Airline
* Route
* Australian City
* International City
* Stops
* Total Flights
* Maximum Seats
* Year & Month

---

## 🔍 Project Workflow

### 1️⃣ Data Cleaning (Python)

* Handled missing values
* Converted data types
* Removed duplicates
* Standardized column names

### 2️⃣ Data Analysis (SQL)

Performed multiple SQL queries to extract insights such as:

* Top airlines by number of flights
* Busiest routes
* Monthly and yearly trends
* Domestic vs International comparison
* Efficiency of airlines based on stops

### 3️⃣ Data Visualization (Power BI)

Created an interactive dashboard including:

* 📊 Flights by Airline
* 🌍 Flights by Country/Route
* 📈 Monthly Trends
* 🏙️ City-wise Analysis
* ✈️ Stops vs Flight Frequency

---

## 📊 Key Insights

* Identified top-performing airlines based on flight volume
* Found busiest routes and destinations
* Observed seasonal trends in flight operations
* Analyzed efficiency of airlines based on number of stops
